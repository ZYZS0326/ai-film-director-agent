# AI 电影导演工作站

面向 AI 短片创作者的本地工作台：从故事想法生成制作方案，并逐镜编辑、锁定、比较修改和恢复版本。

这是**方案与分镜工具**，不是自动成片软件。没有配置模型时使用固定演示模板；演示结果不代表真实创作质量。

## 当前能做什么

- 12个创作环节：导演分析、参考、结构、摄影、美术、剧本、分镜、连续性、提示词、声音、剪辑、审核。
- 制作规格设置、项目搜索、创作/并排/成果视图、Markdown导出。
- 单镜手动编辑与模型候选生成，先比较差异再确认应用。
- 镜头锁定、最近20次操作前的整案快照、版本恢复。
- 确定性检查：总时长、单镜长度、时间线、镜头编号、提示词对应与待复核状态。
- 扩展参考资料：48张原创实操卡覆盖12领域，附11个资料来源入口；支持搜索、领域筛选，并按创作环节送入模型上下文。详见 [参考资料库说明](docs/REFERENCE-LIBRARY.md)。

## 快速开始

建议 Node.js 24（最低22.14），npm。Windows桌面版为主要验证平台。

```sh
npm ci
npm run dev
```

打开 `http://localhost:5173`。后端只监听 `127.0.0.1:8787`。5173端口占用时会明确报错，不会自动换端口。

在「设置」中配置兼容 OpenAI Chat Completions 格式的服务商地址、模型名称和 API Key。内置预设只是配置模板；可用模型、额度与权限以服务商账户为准。本地 Ollama 也可使用兼容接口。

或者复制 `.env.example` 为 `.env` 并填写环境变量。不要提交真实密钥。默认无需密钥即可体验演示流程。

## 推荐工作流

1. 新建项目，设置时长、画幅、剧本等级与目标平台。
2. 写下故事想法，生成方案。
3. 进入「成果 → 分镜」，点击「编辑 / 局部重做」。
4. 对比候选与原稿，确认应用；满意的镜头锁定。
5. 检查待复核项后导出。需要退回时使用版本记录。

原始分镜及提示词说明会保留在「编辑前的原始说明」中，并作为历史附录导出。原始记录可能含旧镜头，当前制作以编辑后的结构化分镜为准。

## 桌面开发与打包

先运行 `npm run dev`，再在另一个终端运行：

```sh
npm run electron:dev
```

Windows构建：

```sh
npm run electron:build
```

安装包输出到 `release/`，完整构建目录为独立的 `buildout-*`。构建不会自动删除旧版本。二进制包应上传 GitHub Releases，不要提交进源码仓库。当前安装包未配置代码签名，Windows可能显示未知发布者提示。

如网络无法下载Electron，可自行设置 `ELECTRON_MIRROR` 或 `ELECTRON_BUILDER_BINARIES_MIRROR`；项目不强制第三方镜像。

## 测试

```sh
npm run typecheck
npm run build
npm test
npm audit --audit-level=high
```

全量测试入口包含编辑、安全边界、UI、模型模拟、停止/并发、解析与数据健壮性检查。测试报告位于 `build/test-reports/`。全量入口不读取项目 `.env`，不使用真实 API Key；模型响应来自本地模拟服务。部分测试使用固定本机端口，请串行运行。

Windows真实界面验收（需先构建）：

```sh
npx electron scripts/workspace-visual.cjs
```

该脚本使用隔离临时数据，检查深浅主题、窄窗口、编辑、锁定与恢复，截图输出到 `build/ui-preview/`。

## 数据与隐私

开发模式默认保存在 `server/data/`，可用 `AI_FILM_DATA_DIR` 指定目录。桌面版使用应用用户数据目录。备份时应关闭应用并复制整个数据目录。

API Key保存在本机设置文件中，**尚未使用系统密钥库加密**。接入远程模型后，相关故事与镜头上下文会发送给所选服务商。不要把本地API暴露到公网。详见 [SECURITY.md](SECURITY.md)。

## 已知边界

- 锁定镜头会阻止可能覆盖它们的整案重跑；尚不支持自动合并新整案与锁定内容。
- 单镜候选不会自动应用，也不会自动重跑下游；修改后需复核连续性、提示词等。
- 版本恢复针对整个方案，尚无任意两个历史版本全文对比。
- 单镜重做暂无取消接口；模型故障或超时可能需要等待请求结束。
- 尚无视觉资产库、视频制作任务看板、生成平台执行与成片验收。
- 外部模型创作质量、大型长片项目及跨平台桌面体验尚未全面验证。
- 测试和依赖审计通过不代表不存在未知缺陷。
